# W21 — `needs[]` derivation: the lesson prerequisite DAG

Generated by `scripts/derive_needs.py`. Derivation only: no lesson record, contract, export or
database was written. Re-running reproduces both artifacts byte for byte.

## Definition

Lesson L needs lesson M iff M != L and L references at least one corpus item that M unlocks. A reference is an explicit, machine-resolvable pointer, from one of five channels: body item chips (<vocab|kanji|grammar ref>, <stroke ref>, <check item-ref>, <flashcard ref>); <sentence ref> in the body, expanded to the sentence's token vocab refs, the kanji in its token surfaces and its grammar tags; the lesson record's own sentence_refs, expanded the same way; each exercise's sentence_refs and answer.sentence_refs, expanded the same way; and <reading ref>, expanded through the reading record's `uses`. Every unlock ref in the course is introduced by exactly one lesson, so an item's introducer is a function. `needs` below is the TRANSITIVE REDUCTION of that relation: direct prerequisites only, each pointing to a strictly EARLIER lesson in course order. Edges that would point FORWARD are course-order defects; they are excluded from `needs` (they would hard-fail validate_lesson_gating check C) and listed in full under forward_edge_defects.

## Acyclicity and the gate conditions

**Acyclic.** A Kahn topological sort over the reduced edge set drains all 322 lessons, leaving none behind; a cycle would have stalled it.

This is not accidental. Every retained edge points to a strictly earlier lesson in
course order, so course order is itself a valid reverse topological order and a cycle
is unrepresentable. The sort is run anyway, as an independent check of the built graph
rather than of the argument for it.

Course order was cross-checked against `course/outline.json`: the topic sequence walked
from `course/manifest.json` + `course/*/course.json` agrees with the outline.
Introduce-once holds: 0 unlock ref(s) are
claimed by more than one lesson, so every item maps to a single introducer.

The three conditions the brief asks to be proved, checked against the derived set:

| condition | result |
|---|---|
| every `needs[].ref` resolves to an exported lesson id | 0 unresolved |
| every `needs[].ref` is strictly earlier in course order | 0 violations |
| every lesson has >=1 need or is a listed root | 322/322 covered |

Those are exactly check C of `validate_lesson_gating.py`, simulated here so the edge set
is known to pass before anyone writes it into a lesson record.

## Forward-edge defects

601 lesson->lesson dependencies point FORWARD: the lesson puts an item in front
of the learner before the course introduces it. These are content defects, not
derivation defects. They are **excluded from `needs[]`** — check C hard-fails on any
need that is not strictly earlier, so shipping them would turn a content bug into a red
gate — and every one is carried in `forward_edge_defects` in the JSON. Nothing is
dropped; the full ledger is below.

| tier | edges | what it means |
|---|---:|---|
| same topic | 27 | a lesson uses what the next lesson in its own topic teaches — the cheapest to fix, usually by swapping two lesson orders or one example |
| same level, different topic | 426 | a topic leans on a later topic at the same level |
| across levels | 148 | an N5 lesson displays an N4/N3 item; this is the sentence-level i+1 backlog check D already freezes |

## Statistics for a placement policy (D2)

Placement asks one question: *if a learner tests into lesson X, what must they already*
*have, and what can they skip?* The DAG answers both.

### Depth and ancestry

`depth` is the longest prerequisite chain ending at a lesson; `ancestors` is the size of
its full prerequisite closure — the true "you must have done these" set. `skippable` is
everything earlier in course order that is *not* an ancestor: the lessons a learner
placing into that lesson can legitimately skip, which a linear course cannot express.

### What the reference graph cannot see

All 41 of the 41 pre-N5 lessons are roots: the whole kana
bootstrap has depth 0 and no derived edge anywhere in it. This is correct by the rule and
wrong for a learner. A hiragana lesson `<check item-ref>`s only its own kana family, so
lesson 15 never *references* what lessons 1-14 unlocked, even though it plainly assumes
them. `design/lesson_schema.md` anticipates this — it exempts kana-bootstrap words from
the linearity rule as "kana-only deps" — but the exemption removes a constraint, it does
not supply the edges. The pre-N5 strand is the one place where a sequential chain has to
be authored rather than derived, and it is small: one edge per lesson, in course order.
This derivation deliberately does not invent them, because a needs edge that no reference
supports would be indistinguishable from the ones that are evidence-backed.

## Judgement calls

1. **Edges are lesson-typed, not item-typed.** `need_type` also allows `vocab`, `kanji`,
   `grammar` and friends, but check C of `validate_lesson_gating.py` resolves *every*
   `needs[].ref` against the exported lesson id map and fails anything else, so an
   item-typed need would be reported as "not an exported lesson". `{type:'lesson',
   ref:'les:...'}` is the only form both gates accept: `validate_lessons.py` resolves it
   through `extra['les']` (lesson slugs, which carry the `les:` prefix) and then checks
   membership in the already-seen set. The driving items survive in `note`.
2. **Bare prose kanji is measured, not shipped.** A kanji inside a `<jp>` span or an
   exercise answer string is text, not an address. Counting it would add 3023 more edges and
   1276 more forward defects, most of them
   the sentence-level i+1 backlog that `validate_lesson_gating.py` check D already holds
   frozen in `research/reports/lesson_sentence_baseline.json`. Check B scopes "reference"
   to addressed item tags for the same reason; this derivation matches it rather than
   inventing a second, wider definition of the same word.
3. **Exercise answers contribute almost nothing, and that is a finding.** Of 1,560
   exercises, 0 carry markup in `prompt` or `answer` and exactly 1 has
   `answer.sentence_refs`; 314 have exercise-level `sentence_refs`. The answer surface is
   plain text, so the "answers" channel the brief names is real but nearly empty. Making
   it carry weight needs `item_refs` on exercises (the field exists in the authoring
   source `research/derived/lessons/*.json` and is empty), not a fuzzier matcher here.
4. **Items no lesson teaches produce no edge.** 54 distinct referenced refs are unlocked by no
   lesson at all — overwhelmingly vocabulary appearing inside displayed sentences that the
   course never formally introduces. There is no lesson to depend on, so they are counted
   here rather than turned into a dangling need.
5. **Self-references are dropped.** 3985 (lesson, ref) pairs
   point at an item the lesson itself introduces — the normal case for a lesson teaching
   its own material, and not a dependency.
6. **The reduction is exact, not heuristic.** Because every edge runs backward in course
   order, course order is a reverse topological order; walking each lesson's prerequisites
   nearest-first and dropping any already reached by a nearer one is the transitive
   reduction, which is unique for a DAG. Reachability is unchanged, and so is every
   longest path, so `depth` is the same before and after.

## What this unblocks

- Check C of `validate_lesson_gating.py` stops printing its standing ADVISORY and starts
  proving something: 700 prerequisites to verify instead of 0.
- G11's remediation edges become expressible: a failed checkpoint can name the exact
  lesson to return to.
- D2 placement gets its input — the ancestor closure per lesson, and the skip set.

## Consistency notes for whoever applies this

- `research/derived/needs_edges.json` holds one record per lesson in course order, each with the `needs` array
  to write, plus `depth` / `ancestors` / `dependents` / `skippable_if_placed_here`.
- The authoring source is `research/derived/lessons/<slug>.json`, not the exported
  `course/**/lesson-*.json`; applying `needs` there and re-running the loader + exporter
  keeps the export regenerable, which is what CLAUDE.md requires.
- 0 sentence ref(s) and 0 reading
  ref(s) failed to resolve against the corpus during the harvest.
